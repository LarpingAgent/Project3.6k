The Poly Haven API also asks applications using its live API service to identify Poly Haven; this repository contains downloaded files and does not call the API at runtime. All downloads were taken from the Poly Haven files API at 1K resolution and verified against the API-reported byte size and MD5. The exact per-file size and digest are recorded in `reference_scene/polyhaven/DOWNLOADS.md` (MD5 values as supplied by the source API).
